### Recipe Editor Features:
- **Title Field**: Single-line text input (required)
- **Category Selector**: Custom dropdown control with recipe categories
- **Ingredients**: Multi-line text area for listing ingredients
- **Instructions**: RichTextBox with formatting toolbar (Bold, Italic, Underline)
- **Time Controls**: NumericUpDown for prep and cook times
- **Servings**: NumericUpDown for number of servings
- **Schedule Date**: Optional DateTimePicker for meal planning
- **Notes**: Additional notes text area
- **Action Buttons**: Save (green), Cancel (red), Export

## Keyboard Navigation

### Main Dashboard
| Key | Action |
|-----|--------|
| Ctrl+N | New Recipe |
| Ctrl+E | Edit Selected Recipe |
| Delete | Delete Selected Recipe |
| Enter (in search) | Search |
| ?? | Navigate recipe list |
| Double-Click | Edit recipe |

### Recipe Editor
| Key | Action |
|-----|--------|
| Ctrl+B | Bold (in RichTextBox) |
| Ctrl+I | Italic (in RichTextBox) |
| Ctrl+U | Underline (in RichTextBox) |
| Tab | Navigate between fields |
| Esc | Cancel (close without saving) |
| Ctrl+S | Save (can be added) |

## Screen Sizes

### Main Dashboard
- **Minimum**: 1024x600
- **Recommended**: 1200x550
- **Default**: 1200x550 (centered)

### Recipe Editor
- **Fixed Size**: 720x470
- **Modal Dialog**: Cannot resize
- **Centered**: Over parent window

## Responsive Behavior

### Main Dashboard
- **DataGridView**: Fills remaining space (Dock.Fill)
- **Search Panel**: Fixed height, full width (Dock.Top)
- **Columns**: Auto-size based on content

### Recipe Editor
- **Fixed Layout**: Non-resizable dialog
- **Tab Order**: Logical flow through fields
- **Focus**: Title field has initial focus

## Visual Feedback

### User Actions
- **Hover**: Buttons show hover state
- **Click**: Button press animation
- **Selection**: Full row highlight in grid
- **Validation**: MessageBox for errors
- **Success**: MessageBox for confirmations

### Data Operations
- **Saving**: Brief pause, then close
- **Loading**: Grid updates immediately
- **Search**: Grid filters in real-time
- **Delete**: Confirmation dialog first

## Accessibility Features

- **Tab Navigation**: All controls in proper tab order
- **Keyboard Shortcuts**: Ctrl+ combinations for common actions
- **Labels**: All fields have descriptive labels
- **Focus Indicators**: Visual feedback for focused controls
- **Error Messages**: Clear, descriptive error dialogs

## Layout Principles

1. **Logical Grouping**: Related fields grouped together
2. **Left-to-Right**: Western reading order
3. **Top-to-Bottom**: Most important fields at top
4. **Consistent Spacing**: 10-15px between controls
5. **Action Buttons**: Right-aligned at bottom
6. **Required Fields**: Marked with validation
7. **Optional Fields**: Clearly indicated (checkbox for date)

## Design Guidelines

### Typography
- **Headers**: Default system font, bold
- **Labels**: Default system font, regular
- **Content**: Segoe UI, 9pt
- **Buttons**: Segoe UI, 9pt

### Spacing
- **Padding**: 10-15px from edges
- **Margins**: 5px between related controls
- **Sections**: 15-20px between sections

### Controls
- **TextBox**: Standard height (23px)
- **Buttons**: Standard height (30px)
- **ComboBox**: Standard height (23px)
- **NumericUpDown**: Standard height (23px)
